# 2026-10-11

## zip2pdf 项目（图片 ZIP 转 PDF 网页）

- 目标：手机浏览器直接访问网址使用，已部署到 GitHub Pages（仓库 Cherise233/zip2pdf，分支 main）。
- 修复 `Cannot destructure property 'jsPDF' of 'window.jspdf' as it is undefined`：
  根因是 cdnjs 的 jsPDF 脚本在 Pages 上未加载成功。
- 本次改动：
  1. 依赖本地化：`vendor/jszip.min.js`（JSZip 3.10.1）、`vendor/jspdf.umd.min.js`（jsPDF 2.5.2），全部改相对路径。
  2. 新增 `ensureLibs()`：本地 vendor 缺失时自动回退 jsdelivr CDN（防止上传时漏掉 vendor 目录）。
  3. 新增 `checkLibs()`：加载失败显示明确原因，不再抛难懂的 destructure 错误。
  4. `sw.js` 升到 v5：navigate 请求网络优先（改代码后手机能立即生效）、静态资源与依赖库缓存优先；缓存清单补齐 vendor 与图标。
  5. IndexedDB 打开失败（file:// 直接打开 / 隐私模式）时给出友好提示而非白屏。
- 验证方式（可复用）：node + vm 模拟浏览器环境加载 vendor 库，确认 `window.jspdf.jsPDF` 为 function；
  提取 HTML 内联脚本用 `new vm.Script()` 做语法检查。
- 注意：本机 `git push` 会因 PortableGit 的 `credential.helper=helper-selector` 弹窗被沙箱拦截而失败，
  需由用户在自己的终端执行 `git push origin main`。变更只提交在本地（657259b / d4e7111）。
